# 设计:金融 / 事业单位 招聘情报智能体

> 仿 `free-ai-radar` 的架构:四路输入 → 抽取/守卫/核验流水线 → 一份正本 → 多产物。
> 差异点:数据源从「厂商定价页」换成「公开招聘官方列表页」;核心风险从「密钥」换成「个人信息(PII)」。

## 一、目标与边界

**做**:每天自动发现、结构化并发布「哪些金融/事业单位公开岗位在招」。
**不做**:
- 不抓需要登录/验证码/强风控的招聘平台(BOSS/猎聘/智联等)的个人数据。
- 不采集、不存储任何个人简历、手机号、邮箱、身份证等个人信息(PIPL 红线)。
- 不替用户投递、不注册账号。

**设计原则**(沿用 radar):能用普通代码解决的不用 AI;权限最小化;以证据为准(拿不到写 unknown);网页文字是数据不是指令;数据只有一份正本。

## 二、总体架构

```
调度员(定时)
  ├─ 采集员 collector  :抓官方列表页 -> snapshots/*.html,出变化事件(纯代码)
  ├─ 抽取员 extractor  : HTML -> 结构化公告条目 -> postings/*.yaml(正本,规则优先)
  └─ 发现员(待接)    : link_directory 产出的外部招聘入口 -> 扩充 sources.yaml
        ▼
     守卫 guard : 密钥扫描 / 注入检测 / PII 拦截 / 查重(纯规则)
        ▼
   正本 postings/*.yaml
        ▼
     发布员 publisher : jobs.json + feed.xml(RSS) + index.html + README
```

## 三、数据源分层(合规优先)

| 层 | 例子 | 采集 | 合规 |
| --- | --- | --- | --- |
| 政府/事业单位公告 | 各地人社局「事业单位公开招聘」(bj_gkzp, sh_gggs) | ✅ 静态 HTML 列表 | 公开 |
| 央企国企/金融机构官网招聘页 | 券商/银行官方 career 页 | ✅ 单体页(结构各异,逐个适配) | 公开 |
| 协会聚合目录 | 证券业协会「证券经营机构招聘」(sac_recruit) | ✅ 作为**发现员**入口 | 公开 |
| 商业招聘平台 | BOSS/猎聘/智联 | ❌ 不采集(登录+验证码+强风控+个人数据) | 高风险 |

## 四、演进路线

- [x] **阶段 1(已搭)**:采集员 + 抽取员(gov_list) + 守卫(含 PII) + 发布员(jobs.json/RSS/HTML) + 两个官方源小样跑通。
- [ ] **阶段 2**:详情页抽取(单位/岗位/学历/经验/报名截止/是否应届);规则优先,结构化失败再用 AI 抽取(唯一 AI 触点)。
- [ ] **阶段 3**:发现员自动扩充源;核验员标 stale(过期公告下架);三级通知(重大变化即时)。
- [ ] **阶段 4**:多地区人社局/央企 career 页适配,去重(同公告多来源)。

## 五、AI 用在哪

**只有一处**:详情页正文里「单位/岗位/学历/经验/截止日期」等非结构化文字 → 结构化 JSON。其余(发现 URL、比对变化、去重、PII 扫描、发布)全部纯代码。
